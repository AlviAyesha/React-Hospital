# React Hospital / DevSurvival OS

Welcome to **React Hospital**, a simulation-based coding school where students learn by fixing broken real-world apps, completing startup-style engineering missions, and receiving AI mentor feedback.

## Project Vision
Transform absolute beginners into job-ready React + Next.js full-stack developers through hands-on debugging, real-world simulations, and personalized AI mentoring.

## Core Agents / Architecture

This project is built and maintained through the collaboration of several specialized agent personas:
- **Agent 1: Product Architect** - Creates PRD, flows, MVP scope, roadmap.
- **Agent 2: Full-Stack Engineer** - Builds Next.js web app, API, database, auth.
- **Agent 3: Mobile Engineer** - Builds Expo mobile app spec and later implementation.
- **Agent 4: AI Tutor Engineer** - Builds AI tutor logic, prompt system, feedback engine, skill memory.
- **Agent 5: QA Agent** - Tests flows, checks bugs, verifies acceptance criteria.

## Documentation
All project specifications, including the PRD, technical architecture, database schema, and MVP plan, are located in the `/docs` directory.

## Getting Started (Local Development)

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack (Web MVP)
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + shadcn/ui
- **Auth/DB:** Supabase (Coming soon)
- **Code Editor:** Monaco Editor
- **AI Integration:** Vercel AI SDK
