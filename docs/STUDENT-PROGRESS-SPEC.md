# Student Progress Specification

## Progress Components

### 1. XP (Experience Points)
- **Bug Fix**: 50-200 XP (based on difficulty)
- **Daily Lesson**: 50 XP
- **Code Challenge**: 100 XP
- **Streak Bonus**: Multiplier on daily actions.

### 2. Levels
Students progress through levels based on cumulative XP.
- **Level 1 (0-1000 XP)**: Survivor
- **Level 2 (1000-2500 XP)**: Resident
- **Level 3 (2500-5000 XP)**: Attending
- ... up to **Level 10: CTO / Chief of Surgery**.

### 3. Skill Memory
Tracks mastery of specific React/Next.js concepts.
- Mastery score increases on successful bug fixes.
- Mastery score decreases slightly over time if not practiced (spaced repetition).
- Used to personalize the AI Tutor's hints and difficulty of new cases.

### 4. Streaks
Consecutive days of activity.
- Resets if no activity for 24 hours.
- Visual feedback on both web and mobile dashboards.
